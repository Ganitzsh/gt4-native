# Spike R5: what else is in the scene target

Status: answered on `race_boot.cap` (the event screen, the flyover, the grid and the race), 2026-11-08, lane B.
Question and method: RISKS.md R5. Tooling: a local diagnostic (never pushed) that, per Light command, lists the
draws into its target before it with their state, the targets they sample, and the draws after it that read the
target; and `GT4_GSN_DRAWS=all` for one race frame (VBlank 4400, with the mirror). The scene split was on.

## 1. One scene target, one Light a frame

Every phase has one scene target, 640 x 448 at bp 1A40 (32-bit), with one Light command a frame. The rear-view
mirror is drawn into the same target with a smaller scissor (190-449, 20-77): 655 of the race's 840 frames have
it (the Light's inset).

## 2. What is drawn into it before the Light, a race frame

After the race's first 300 frames (540 frames):

| Class | A frame | Where in the order | What it is | The modern view |
|---|---|---|---|---|
| Tagged model runs, main view (view 4) | 531 | throughout, in passes | the course and the cars | draws them (B7) |
| Tagged model runs, mirror (view 5) | 76 | the last fifth | the mirror's view | its own view (B9) |
| An untagged model run | 1 | first | Z test ALWAYS, no Z write, untextured, additive (`Cs As + Cd`) | open (a) |
| Full-screen clear, colour and Z | 1 | first | the frame's clear | compositor keeps |
| Z clears (sprites, Z test ALWAYS, colour RGB kept or not) | 2.7 | between passes | GT4's depth partitions: each pass with its own near and far | ignored (b) |
| Z-only clear by an alpha test that never passes (fail: Z) | 2.3 | between passes, and the mirror's | the same | ignored (b) |
| Z-only full-screen sprite sampling the scene target itself, alpha test NOTEQUAL 0 | 1 | 0.02 | Z set where the colour's alpha is not 0 | compositor keeps (c) |
| Alpha-only full-screen fill, no Z test | 1 | 0.47 | resets destination alpha mid-frame | (d) |
| Full-screen sprite of a 64 x 64 target (t76) blended `Cs Ad + Cd` | 1 | 0.48 | adds a low-resolution render where the draws since the fill marked alpha | (d) |
| Full-screen `Cd x 0x7F / 0x80` | 1 | 0.48 | a near no-op multiply | (d) |
| The mirror's frame: darkening, lines, a Z clear, in its rectangle | 0.7 | last | | compositor keeps |

Most model draws are opaque (Z test GEQUAL, Z write, alpha test GEQUAL 0x20). About 90 a frame are alpha-blended
(`(Cs - Cd) As + Cd`), with or without Z write. The car paint's reflection pass (about 14 draws a frame) samples
the 256 x 256 environment map (t58) with the destination alpha test and a fixed blend, Z test without Z write.

Notes for the substitution (B8) and its order:
- (a) The untagged model run, one a frame, first: not identified yet (sky dome or a backdrop are the candidates).
  It is drawn before the view's first pass, so keeping it on the GS path under the view's colour works only if
  the view writes alpha or blends over it.
- (b) GT4 draws the main view in several depth partitions (a projection of its own near and far per instance, a.8)
  and clears Z between them. The modern view uses one reverse-Z depth (a.8's `cameraToClip`), so these clears
  have no meaning for it; on the GS path they stay.
- (c) Z from the colour target's own alpha, before the view's passes.
- (d) Three full-screen draws sit at 0.47-0.48 of the order, between the view's passes. If the view's colour
  replaces the target at the Light, they are lost: B8 must draw the view in two parts around them, or the modern
  view must reproduce them. What t76 holds (a 64 x 64 target the frame renders models into, then fills alpha) is
  the open question here; R3's prototype should name it.

## 3. What reads it after the Light

Nothing is drawn into it between the Light and the next frame. It is read whole, once into each of the two
640 x 224 24-bit field buffers (t2 and t3): GT4's post chain reads the scene target as a picture. So the GS
targets the modern renderer must also fill are only the scene target itself (colour, and the Z later draws test):
the environment map (t58) and t76 are read by the scene, not after it.

## 4. Open, for R3 and B8

1. The untagged run (a): its draw and its texture.
2. t76 and the full-screen draws at 0.47 (d): what they render, and whether the view is split around them or the
   modern view does them.
3. The flyover and the event screen match the race except for the mirror; the night routes (Route 5) and the
   showroom are not in this capture: R3 covers them.
4. Day only. At night R11 found the light-image glow (draw 326: the reflection view spread over the road) weighted
   by the scene's alpha on Route 5; whether it comes before or after the Light is not in this capture, so
   "nothing is drawn into it after the Light" holds for this day race. The Route 5 night order is open (R3, or a
   look at `r5_ss_ab.cap`).
5. Destination alpha is load-bearing: Z is set from it (c), t76 is added by it (d), the paint's reflection pass
   tests it, and at night the glow is weighted by it. B8 must write GT4's alpha into the target, not only colour
   and Z (CONTRACTS a.5.7).
6. `race_boot.cap`'s race is in fields mode: its display shows a 640 x 224 field a VBlank (VBlank 4400: circuit 2,
   buffer 4480, 640 x 224), so the post chain reads the 448-line scene target into two 224-line field buffers. A
   progressive race (the default) reads it into a full-height buffer instead; B8's read check covers both.
